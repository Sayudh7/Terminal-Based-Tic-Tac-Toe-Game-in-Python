# Terminal-Based-Tic-Tac-Toe-Game-in-Python
A terminal-based Tic-Tac-Toe game built in Python for two players. Users take turns placing X and O on a 3×3 board by entering position numbers. The program validates inputs, detects wins and draws, displays the board after each move, and allows players to start a new game after each round.
# Interactive Tic-Tac-Toe Game in Python

## Description
A simple terminal-based Tic-Tac-Toe game built using Python. It allows two players to play interactively on a 3×3 grid using the command line. The game handles input validation, win detection, draw conditions, and supports replaying multiple rounds.

## Features
- Two-player mode (X and O)
- Interactive terminal interface
- Input validation (prevents invalid or repeated moves)
- Win and draw detection
- Replay option after each game

## How to Run
1. Make sure Python is installed 
2. Download or clone the repository.
3. Run the script:

```bash
python tic_tac_toe.py

Game Rules
Players take turns marking a position (1–9).
First player to align 3 symbols horizontally, vertically, or diagonally wins.
If all positions are filled without a winner, the game ends in a draw.
